# Brandon Sandhu — Portfolio

Welcome — this repository hosts my research papers and notes. Below is a quick portfolio listing of the available papers with direct links to the PDFs.

## Papers

Below are the papers included in this repository, grouped by topic. Click a title to download the PDF.

### Prime Number Theory and Cryptography
- **Combinatorial Sieve Methods** — Surveys combinatorial sieve techniques such as the Brun and Selberg sieves and their applications to prime distribution problems. [Download PDF](combinatorial_sieve_methods.pdf)
- **The Prime Number Theorem** — Explores the statement and proof ideas behind the Prime Number Theorem, connections to the Riemann zeta function, and implications for prime gaps. [Download PDF](prime_number_theorem.pdf)
- **Elliptic Curve Cryptography** — Introduces ECC, covering elliptic curves over finite fields, key exchange, and signature schemes, with security considerations and parameter guidance. [Download PDF](elliptic_curve_cryptography.pdf)

### Large Language Models
- **Transformer Architecture** — Derives the Transformer architecture from first principles, covering embeddings, scaled dot-product self-attention, multi-head attention, residual connections, and training details. [Download PDF](transformer_architecture.pdf)

### Parallelism using OpenMP and MPI
- **Hybrid N-Body Simulation (OpenMP + MPI)** — Describes a hybrid N-body simulation combining OpenMP threading and MPI message-passing, with optimization and scalability results. [Download PDF](n_body_sim_hybrid_openmp_mpi.pdf)
- **Domain Decomposition with MPI** — Implements domain decomposition using MPI to parallelize a 2D simulation and analyses communication patterns and performance. [Download PDF](domain_decomp_mpi.pdf)
- **Parallel Graph Connectivity Analysis** — Reviews parallelization methods for computing connectivity statistics on large graphs and compares performance and scalability. [Download PDF](graph_connectivity_parallelism.pdf)

### Epidemiology & Disease Modelling
- **Ross-Macdonald Spatial Kernel Model** — Presents a spatial-kernel Ross–Macdonald model for host–vector transmission with numerical examples. [Download PDF](ross_macdonald_spatial_kernel_model.pdf)
- **SIR Model — Frequency-Dependent Mixing** — Studies the SIR model without demography under frequency-dependent mixing and examines epidemic trajectories. [Download PDF](SIR_no_demography_freq_mixing_model.pdf)
- **STH Transmission Model** — Develops a deterministic model for soil-transmitted helminth transmission and evaluates intervention strategies. [Download PDF](STH_transmission_model.pdf)
- **SIR Model (No Demography)** — Analyses the canonical SIR model without demography and derives epidemic curves and threshold conditions. [Download PDF](SIR_no_demography_model.pdf)
- **Short-Term Transmission Dynamics** — Uses an SEIR-style model to study short-term measles dynamics with numerical examples and control implications. [Download PDF](short_term_transmission_dynamics.pdf)

### Misc
- **Hidden Markov Models** — Describes design and implementation of an HMM for time-series prediction, covering parameter estimation and decoding. [Download PDF](hidden_markov_models.pdf)
- **Boolean Functions — Notes** — Lecture notes on Boolean functions, including DNF/CNF, implicants, and combinatorial properties. [Download PDF](notes_boolean_functions.pdf)
